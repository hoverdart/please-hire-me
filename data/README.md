# Discovery seeds and public research

These files give job discovery somewhere to start. If you want to understand where listings come from or help improve the sources, start here. To change which roles and locations fit your own search, use **Preferences**; see [Make it yours](../README.md#make-it-yours).

| File | Use |
| --- | --- |
| `boards.md` | ATS slug seeds from a historical public board snapshot; counts and availability can be stale |
| `slug-candidates.txt` | Slug candidates, including dead or unknown boards |
| `sources.md` | Historical public sourcing ideas; not application eligibility policy |

Discovery records current source health in the private ledger. Packaged copies of board seeds live in `hireme/resources/` for wheel installations. Verify current postings instead of treating historical research as current requirements or applicant facts.

Applicant documents, working queues and private research belong in `~/.local/share/please-hire-me/`. Legacy ignored files in this checkout remain available for migration. `scripts/probe_boards.sh` writes discovery results to the ledger without rewriting tracked seed data.
